### 2.2 环境变量

| 变量 | 默认值 | 策略 |
|---|---|---|
| `PORT` | 空 | 最高优先级监听地址 |
| `JADE_ADDR` | 空，最终默认 `:28473` | 次优先级监听地址 |
| `JADE_JWT_SECRET` | 无默认值 | 空则打印错误并停止启动，禁止默认密钥 |
| `JADE_ADMIN_KEY` | 空 | 为空时所有管理接口 503 |
| `JADE_DATA_DIR` | `data` | SQLite 与 manifest 目录 |
| `JADE_PATCH_DIR` | `patches` | PCK 补丁目录 |

### 2.3 数据表

| 表 / 结构 | 关键字段 |
|---|---|
| `users` | `id`, `device_id`, `username`, `password_hash`, `is_guest`, `created_at`, `last_seen_at` |
| `cloud_saves` | `user_id`, `save_rev`, `realm_name`, `spirit_stones`, `play_seconds`, `payload`, `updated_at`，迁移追加 `realm_order`, `cultivation_xp`, `tower_floor` |
| `mails` | `id`, `target_uid`, `title`, `body`, `spirit_stones`, `items_json`, `created_at`, `expires_at` |

### 2.4 客户端对接

| 项目 | 现状 |
|---|---|
| 服务地址 | `https://allplayer.cn:28474` |
| 登录接口 | `/api/auth/login` |
| 云档接口 | `/api/save/meta`, `/api/save/upload`, `/api/save/download` |
| 其他接口 | `/api/leaderboard`, `/api/ping`, `/api/mail/list`, `/api/mail/claim` |
| 请求头 | `Content-Type: application/json`；token 非空时 `Authorization: Bearer <token>` |
| 请求字段 | 云档上传含 `base_rev`, `force`, `realm_name`, `spirit_stones`, `play_seconds`, `realm_order`, `cultivation_xp`, `tower_floor`, `payload_gzip_b64` |
| 版本字段 | 客户端请求中未见 `version` / `build` / `channel` |
| 401 处理 | 发一次 `auth_expired`，保留本地玉简 |
| 409 处理 | 暂停同步，发出 `save_conflict_detected` |
| 归属保护 | 本地归属 UID 不匹配时阻止自动同步，提示二选一 |
| 归属硬锁 | 冲突后 300 秒内禁止自动上传 |

### 2.5 热更新流程

| 阶段 | 现状 |
|---|---|
| 补丁目录 | `user://patches` |
| 状态文件 | `user://patch_state.json` |
| 查询 | `/api/version?patch_rev=<current>`，超时 3 秒 |
| 下载 | `HTTPClient` 分块，每帧 24 个 chunk |
| 续传 | `.tmp` + `.tmp.meta`，校验相同 `rev` 与 `sha256` 后续传 |
| 校验 | `FileAccess.get_sha256()` 与 manifest 强比对 |
| 挂载 | `ProjectSettings.load_resource_pack(path, true)` |
| 失败回退 | 删除残包、移除已安装记录、留在启动页重试 |
| 成功清理 | 清理旧 `.pck`、`.tmp`、`.tmp.meta`，重建 `DataRegistry` / `IconLibrary` 缓存 |

### 2.6 安全策略

| 领域 | 现状 |
|---|---|
| JWT | HS256，30 天有效，密钥 `JADE_JWT_SECRET` 必填 |
| 密码 | bcrypt，长度 6–72 字节 |
| 管理接口 | `X-Admin-Key`，常量时间比较；未配置返回 503，不匹配 401 |
| 管理页 | `/admin` 页面公开，接口另需 key |
| CORS | `Access-Control-Allow-Origin: *` |
| 路径穿越 | `/patches/` 拒绝 `..`、`/`、`\`，仅允许 `.pck` |
| 补丁上传 | 上限 512MB + 32MB，仅 `.pck`，计算 SHA256 |
| 云档上传 | JSON 1MB 限制，gzip 后 1B–512KB，事务内乐观锁 |
| TLS | 源码未配置 TLS 监听器，部署依赖外部反代 |
