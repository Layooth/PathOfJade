## 六、TEMPLATES 键名与 SVG 规范

- 文件声明：`class_name IconSvgPack`，`extends RefCounted`。
- 键名统一使用小写 snake_case，按用途加前缀：
  - `nav_`：导航
  - `ui_`：通用界面
  - `skill_`：百艺技能
  - `tech_`：功法
  - `enemy_`：妖兽
  - `item_`：物品、丹药、符箓
  - `equip_`：装备
  - `seed_`：灵种
  - `tool_`：工具
  - `gear_`：法器宝具
  - `farm_`：灵田
  - `tribulation_ring_`：渡劫阵盘
- 模板 key 是图标形状键，不一定等于物品 ID。
- 物品通过 `ITEM_KEY_MAP` 做 `item_id -> template_key` 映射；缺失时由 `IconLibrary` 兜底。
- 画布统一 `viewBox="0 0 48 48"`，根节点通常 `fill="none"`，不写固定 `width` / `height`。
- 占位色：
  - `{C1}`：主线条色
  - `{C2}`：点缀 / 微光色
- 常规线宽：
  - 主轮廓：2.2
  - 细节：1.4 至 1.8
  - 点缀：2.0 至 2.4
- 常用填充透明度：0.10 至 0.35。
- 线帽与转角多用 `round`。
- 个别专用模板可固定点缀色，例如太极符使用 `#A87424`，但键名与 `viewBox` 规范保持一致。
