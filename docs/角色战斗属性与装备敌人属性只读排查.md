## 1. 玩家战斗属性汇总公式与战斗判定

### 1.1 基础常量

| 名称 | 值 | 用途 |
|---|---:|---|
| `BASE_ATTACK` | 8 | 无境界数据时的保底攻击 |
| `BASE_DEFENSE` | 2 | 无境界数据时的保底防御 |
| `BASE_ACCURACY` | 0.85 | 玩家基础命中 |
| `BASE_ATTACK_INTERVAL` | 2.2 秒 | 玩家基础攻击间隔 |
| `QUALITY_MULTIPLIERS` | `[1.0, 1.2, 1.4]` | 凡品/精良/极品装备属性倍率 |
| `TEMPER_CRIT_CAP` | 0.25 | 兵刃祭炼会心加成上限 |
| `ENEMY_ACCURACY` | 0.95 | 敌人普攻命中判定固定值 |

装备属性进入汇总前统一走 `_equip_stat(slot, key)`：

```text
quality = clamp(equipment[slot].quality, 0, 2)
equip_stat = item.<对应属性> * QUALITY_MULTIPLIERS[quality]
```

### 1.2 境界道体倍率

```text
base     = REALM_COMBAT_MULT[clamp(realm.tier, 0, size-1)]
stageMod = 1.0 + 0.06 * clamp(realm.stage - 1, 0, 2)
realm_combat_mult = base * stageMod
```

境界数组为 `[1.0, 1.5, 3.0, 6.0, 12.0, 25.0, 50.0, 100.0, 200.0]`。

### 1.3 气血上限 `get_max_hp()`

```text
base = realm.max_hp 或 100

total = base
      + round(weapon.max_hp_bonus + armor.max_hp_bonus)
      + crimson_fruit_hp_bonus(crimson_fruit_eaten)
      + temper_hp_bonus(armor_temper_level)

total *= 1.0 + technique("max_hp")
total *= 1.0 + effect_sum("max_hp_pct") + codex_bonus("max_hp")
total *= 1.0 + temper_pct("armor")
total *= 1.0 + natal_bonus("max_hp_pct")
total *= 1.0 + FiveElementsSystem.bonus("hp_def_pct")
total *= realm_combat_mult

max_hp = round(total)
```

夹取：无最终上下限；装备品质索引在 `_equip_stat()` 中夹取到 `0..2`。

### 1.4 攻击力 `get_attack()`

```text
base = realm.attack 或 BASE_ATTACK

total = base
      + round(weapon.attack_bonus + armor.attack_bonus)
      + crimson_fruit_attack_bonus(crimson_fruit_eaten)
      + temper_attack_bonus(weapon_temper_level)

total *= 1.0 + technique("attack_pct")
total *= 1.0 + codex_bonus("attack")
total *= 1.0 + temper_pct("weapon")
total *= 1.0 + natal_bonus("attack_pct")
total *= 1.0 + FiveElementsSystem.bonus("attack_pct")
total *= realm_combat_mult

attack = round(total)
```

夹取：无最终上下限。

### 1.5 防御力 `get_defense()`

```text
base = realm.defense 或 BASE_DEFENSE

total = base
      + round(weapon.defense_bonus + armor.defense_bonus)
      + temper_defense_bonus(armor_temper_level)

total *= 1.0 + technique("defense")
total *= 1.0 + codex_bonus("attack")        # 当前代码确实复用 attack 图鉴加成
total *= 1.0 + temper_pct("armor")
total *= 1.0 + natal_bonus("defense_pct")
total *= 1.0 + FiveElementsSystem.bonus("hp_def_pct")
total *= realm_combat_mult

defense = round(total)
```

夹取：无最终上下限。

### 1.6 命中率 `get_accuracy()`

```text
accuracy = BASE_ACCURACY
         + (weapon.accuracy_bonus + armor.accuracy_bonus) / 100.0

accuracy = clamp(accuracy, 0.3, 0.99)
```

上下限：`0.30 ~ 0.99`。

### 1.7 闪避率

当前项目中：

- `GameState.gd` 没有 `get_dodge()` / `dodge_chance` / `闪避率` 汇总字段。
- `ItemData.gd` 没有 dodge/evade 字段。
- `EnemyData.gd` 没有 dodge/evade 字段。
- `ENEMY_DEFS` 没有配置任何命中/闪避/会心字段。

结论：**玩家与敌人均没有真正可成长的闪避属性**。战斗日志里的“闪开/扑空”只是命中判定失败的视觉事件，不读取闪避率。

补充：`EnemyData` 有 `accuracy: float = 0.9` 字段，但 `CombatEngine._enemy_attack()` 并未使用它，而是直接使用全局常量 `ENEMY_ACCURACY = 0.95`。

### 1.8 会心率

原始会心率：

```text
crit_raw = technique("crit_chance")
         + temper_crit_chance(weapon_temper_level)
         + natal_bonus("crit_chance")

temper_crit_chance = min(0.0015 * weapon_temper_level, 0.25)
```

面板会心率：

```text
crit_display = clamp(crit_raw, 0.0, 0.75)
```

战斗判定会心率：

```text
crit_trigger = clamp(crit_raw, 0.0, 0.75)
```

会心伤害倍率：

```text
if crit_raw > 0.75:
    crit_mult = 1.75 + (crit_raw - 0.75) * 1.5
else:
    crit_mult = 1.75
```

上下限：触发概率封顶 `75%`；溢出部分不浪费，按 1:1.5 转为会心伤害倍率。

### 1.9 攻击间隔 `get_player_stats().interval`

```text
interval = BASE_ATTACK_INTERVAL
         * max(0.5, 1.0 + technique("attack_interval"))
         * max(0.5, 1.0 - natal_bonus("attack_interval_reduction"))
         * max(0.5, 1.0 - FiveElementsSystem.bonus("attack_interval_reduction"))

interval = max(0.55, interval)
```

夹取：三段独立下限 `0.5`，最终硬下限 `0.55 秒`。

`CombatEngine` 使用时再次夹取：

```text
player_attack_interval = max(0.55, stats.interval)
enemy_attack_interval  = max(0.5, enemy.attack_interval)
```

### 1.10 战斗实际判定公式

#### 玩家普攻命中

```text
if randf() > stats.accuracy:
    未命中（敌人侧闪避视觉事件）
else:
    命中并结算伤害
```

即命中概率就是 `stats.accuracy`，范围 `0.30 ~ 0.99`；敌人没有独立闪避率。

#### 敌人普攻命中

```text
if randf() > ENEMY_ACCURACY:  # 0.95
    未命中（玩家侧闪避视觉事件）
else:
    命中并结算伤害
```

即敌人固定 95% 命中，玩家没有独立闪避率。

#### 防御减伤 / 单次伤害

`GameFormulas.compute_damage()`：

```text
roll  = randf_range(0.85, 1.15)
raw   = attacker_attack * roll - defender_defense * 0.6
damage = max(1, round(raw))
```

说明：

- 防御不是百分比免伤，而是按 `defense * 0.6` 做固定减免。
- 伤害保底 1 点，不会因为高防御归零。

期望伤害（离线/DPS 估算）：

```text
expected_damage = max(1.0, attack - defense * 0.6)
```

#### 玩家会心

```text
if crit_raw > 0 and randf() < clamp(crit_raw, 0, 0.75):
    damage = round(damage * (1.75 + max(0, crit_raw - 0.75) * 1.5))
```

#### 剑气真伤

```text
每第 3 次普攻：
qi_damage = max(1, round(stats.attack * technique("sword_qi")))
damage += qi_damage
```

#### 破厄剑茶增伤

```text
damage = round(damage * (1.0 + FishingTeaSystem.bonus("combat_damage")))
```

#### 护身符减伤（敌人攻击与天雷共用口径）

```text
ward_ratio = clamp(best_ward_ratio + technique("ward_bonus"), 0.0, 0.9)
damage = max(1, round(damage * (1.0 - ward_ratio)))
```

敌人普攻只在 `damage >= 10` 时自动消耗护符；天雷在开启自动用符时消耗护符。

### 2.2 法宝祭炼 `equip_temper_levels` 加成规则

祭炼等级按槽位独立保存，不绑定具体装备 id：`weapon` / `armor`。

| 槽位 | 祭炼每 1 重加成 | 上限/阶段性效果 |
|---|---|---|
| 武器 `weapon` | 攻击固定 +15；会心 +0.15%；总攻击乘区 +1.2% | 会心祭炼加成封顶 +25%；每 5 重全百艺双倍 +0.5%（整数除法） |
| 护甲 `armor` | 气血固定 +180；防御固定 +10；气血/防御乘区 +1.2% | 每 5 重全百艺耗时 -0.5%（整数除法） |

公式对应关系：

```text
temper_attack_bonus   = weapon_temper_level * 15
temper_crit_chance    = min(weapon_temper_level * 0.0015, 0.25)
temper_double_bonus   = 0.005 * floor(weapon_temper_level / 5)
temper_pct("weapon")  = 0.012 * weapon_temper_level

temper_hp_bonus       = armor_temper_level * 180
temper_defense_bonus = armor_temper_level * 10
temper_pct("armor")   = 0.012 * armor_temper_level
temper_interval_reduction = 0.005 * floor(armor_temper_level / 5)
```

### 3.1 中后期妖兽是否具备闪避或高防机制

结论：

1. **没有闪避机制**  
   24 个敌人的 `ENEMY_DEFS` 均未配置 `dodge` / `evade` / `accuracy` / `crit` 字段。玩家装备的命中属性不会因为敌人闪避而被额外消耗。

2. **没有敌人会心机制**  
   敌人不会触发会心，玩家会心率也不会被敌人抗性削减。

3. **有高防御机制**  
   敌人防御从前期 `2~36`，中期 `48~230`，后期 `300~780`，终局 `1100~2600` 递增。  
   它只通过 `damage = attack * roll - defense * 0.6` 扣减伤害，不影响命中概率与会心触发率。

4. **玩家命中率实际用途有限**  
   命中率上限 0.99，但敌人无闪避字段，因此玩家命中只决定 `randf() > accuracy` 的失败概率；装备命中属性主要把玩家从 0.85 基础命中推向上限，而非对抗敌人闪避。

5. **敌人命中固定 95%**  
   `EnemyData.accuracy` 字段没有参与战斗；敌人普攻命中固定 0.95，玩家没有闪避属性可降低该值。
